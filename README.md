# 🎲 Activity Generator (Fullstack App)

Веб-приложение, которое помогает определиться, чем заняться, в зависимости от вашего настроения и типа дня. Проект написан с нуля: от базы данных на Java до красивого интерфейса на React.

## ✨ Основной функционал
*   **Умный подбор:** Выбор активности по настроению (Lazy, Active, Social, Creative) и типу дня (Будний, Выходной, Любой).
*   **Без повторений:** Приложение запоминает, какие активности вы уже видели, и не показывает их снова.
*   **Темная тема:** Переключение между светлой и темной темой с сохранением выбора в браузере.
*   **Обработка ошибок:** Если активности закончились или сервер недоступен, пользователь увидит красивое сообщение, а не белый экран.

## 🛠 Технологии
**Бэкенд (Backend):**
*   Java 17+
*   Spring Boot (REST API)
*   Spring Data JPA
*   База данных H2 (In-Memory)
*   Maven

**Фронтенд (Frontend):**
*   React (Vite)
*   Axios (для HTTP-запросов)
*   CSS3 (Переменные, анимации, Flexbox)
